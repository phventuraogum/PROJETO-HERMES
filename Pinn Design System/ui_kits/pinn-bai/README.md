**What it is:** B2B intelligence + dashboards SaaS — the "data brain" SKU of Pinn. Operates in **dark mode** (the only Pinn surface that does), with Pinn Orange as the only chromatic accent.

**Status:** inferred from brandbook description (`pinnbai.lovable.app`, "paleta laranja+dark"). No live source provided. Calibrate against running app before production.

## Components
- `Sidebar.jsx` — collapsed nav, ICP / accounts / signals / agents / dashboards
- `TopBar.jsx` — workspace switcher, search, account badge
- `AccountTable.jsx` — sortable B2B account list (CNPJ, score, sinal, status)
- `SignalCard.jsx` — qualifying-signal callout (orange accent)
- `KPI.jsx` — executive KPI tiles
- `AgentRunPanel.jsx` — agent execution log (terminal-style)
